# VentureScout live agent graph

`agents/graph.py` is the production LangGraph workflow.

Runtime requirements:

```env
AGENT_LLM_PROVIDER=bedrock
RETRIEVAL=live
BEDROCK_SONNET_MODEL_ID=us.anthropic.claude-sonnet-4-6
```

The workflow:

```text
Structuring
  -> Market / Competitor / Tech / IP / Business Model
  -> Critic
  -> Evidence Board
```

- Structuring uses the submitted input and rejects insufficient descriptions.
- All analysis text is generated by Amazon Bedrock Claude.
- Evidence and patent candidates come from live PostgreSQL/pgvector retrieval.
- Bedrock, authentication, JSON parsing, or retrieval failures stop the run.
- Fixed analysis content is not substituted when an external dependency fails.

For a CLI run:

```powershell
$env:VENTURESCOUT_RAW_INPUT="대상 고객, 문제, 해결책과 수익모델을 포함한 사업 아이디어"
python scripts/run_bedrock_graph.py
```
